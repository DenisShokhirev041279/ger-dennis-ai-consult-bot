## СТРАТЕГИЯ ПРОДУКТА

### Воронка конверсии (3 уровня):

**Уровень 1 — Бесплатные AI-инструменты (Lead Magnet):**
- Brand Audit: загрузи лого → получи AI-анализ визуала
- Product Photo: загрузи фото товара → получи фото без фона
- Social Media Kit: одно фото → нарезка для всех соцсетей
Это БЕСПЛАТНО. Цель: WOW-эффект → пользователь рассказывает друзьям → вирус.

**Уровень 2 — Подписка (Recurring Revenue):**
- Starter (1990★/мес): 30 запросов/день, базовый CV
- Pro (5990★/мес): безлимит, продвинутый CV, генерация картинок, MagicHour видео
- Business (14990★/мес): всё + 30 мин консультации/мес + кастом

**Уровень 3 — Premium / B2B:**
- Разовые консультации (существующие пакеты) остаются как upsell
- White label — "хочешь такого же бота для своего бизнеса?" (будущее)

### Реферальная механика:
- Каждый юзер получает реферальную ссылку
- Привёл друга = +5 бесплатных сообщений
- Друг купил подписку = +10% первого платежа бонусом
- Это создаёт вирусный loop: бесплатный инструмент → WOW → поделился ссылкой → новый юзер
